# Лабораторная работа №4
## Тема
Линейный массив
## Цель работы
Изучить способы хранения и обработки одномерных массивов.
## Задания
1.1В одномерном массиве, состоящем из п целых элементов определить:
1.2 число соседств двух положительных чисел,двух чисел разного знака и двух
чисел одного знака;
1.3 количество подряд идущих отрицательных элементов;
1.4 номер элемента, имеющего максимальное количество целочисленных
делителей.

2.1. В одномерном массиве, состоящем из п целыхэлементов, найтипервый
положительный двузначный элемент, который не делится на 6.
2.2. В одномерном массиве, состоящем из п целыхэлементов удалить все
отрицательные элементы.
2.3. В одномерный массив, состоящий из п целыхчисел вставить новый элемент
после всех минимальных элементов

3.1. В одномерном массиве, состоящем из п целыхэлементов. Упорядочить
отрицательные элементы массива по неубыванию.
3.2. Дан целочисленный массив A размера N. Переписать в новый
целочисленный массив B все четные числа из исходного массива (в том же
порядке) и вывести размер полученного массива B и его содержимое.
