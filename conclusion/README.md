# Итоги курса

## Общая информация

В данном репозитории представлены лабораторные работы по дисциплине «Программирование на Python», выполненные в процессе изучения базовых конструкций языка и структур данных.

---

## Выполненные лабораторные работы

### Лабораторная работа №1
**Линейные программы**

Изучены:
- ввод и вывод данных;
- арифметические операции;
- работа с переменными;
- вычислительные алгоритмы.

➡️ Перейти: [Lab 1](../lab1_linear_programs)

---

### Лабораторная работа №2
**Циклы**

Изучены:
- цикл `for`;
- цикл `while`;
- вычисление сумм и произведений;
- повторяющиеся алгоритмы.

➡️ Перейти: [Lab 2](../lab2_loops)

---

### Лабораторная работа №3
**Использование строковых переменных**

Изучены:
- обработка строк;
- поиск и замена символов;
- работа с подстроками;
- строковые методы Python.

➡️ Перейти: [Lab 3](../lab3_strings)

---

### Лабораторная работа №4
**Линейный массив**

Изучены:
- списки Python;
- поиск элементов;
- сортировка;
- обработка массивов данных.

➡️ Перейти: [Lab 4](../lab4_arrays)

---

## Полученные навыки

В ходе выполнения лабораторных работ были освоены:

- основы программирования на Python;
- создание линейных и циклических алгоритмов;
- обработка строковых данных;
- работа с одномерными массивами;
- использование Git и GitHub для хранения проектов.
