
# Лабораторная работа №1
## Тема
Линейные программы
## Цель работы
Изучить основные конструкции языка Python и разработать программы линейной структуры.
## Задания
1. Даны координаты трех вершин треугольника: (x1, y1), (x2, y2), (x3, y3). Найти
его периметр и площадь, используя формулу для расстояния между двумя точками на
плоскости. Для нахождения площади треугольника со сторонами a, b,
c использовать формулу Герона, где p = (a + b + c)/2 — полупериметр.

2. Написать программу не используя условный оператор. На экран вывести TRUE
или FALSE 3) целое k является трехзначным числом, кратным пяти;

3. Запишите логическое выражение, которое принимает значение "TRUE" тогда и
только тогда, когда точка с координатами (x, y) принадлежит заштрихованной области
и FALSE в противном случае
