# Лабораторная работа №3

## Тема
Использование строковых переменных
## Цель работ
Освоить методы обработки строк в Python.
## Задания
1. Предложение состоит из слов. Между словами один или несколько
пробелов, после последнего слова точка. Подсчитать суммарное вхождение
букв "М", "Н" в предпоследнее слово и удалить в нем все буквы "Н".
Выполнить двумя способами:
а) рассматривая строку как массив символов;
б) используя процедуры и функции для обработки строк.
2. Предложение состоит из слов. Между словами один или несколько
пробелов, после последнего слова «.». Определить число слов в предложении,
начинающихся и заканчивающихся одной и той же буквой и вывести эти
слова в порядке обратном алфавитному. (Разбить предложение на массив
слов).
3. Дана строка символов, состоящая из цифр и пробелов. Группы цифр,
разделенных пробелами одним или несколькими и не содержащими пробелов
внутри себя, будем называть словами. Требуется подсчитать количество слов
в данной строке. Рассматривай слова как числа, определить сумму и
количество нечетных чисел, делящихся на 3 без остатка.
4. На вход программе подается последовательность символов, состоящая
из букв латинского алфавита и цифр. Ввод символов заканчивается
восклицательным знаком.
Требуется написать, как можно более эффективную программу, которая
из всех четных цифр, встретившихся в строке, формирует наименьшее число
(без повторения цифр) и выводит на экран факториал этого числа деленный на
500. Если таких цифр нет, то программа выводит нуль. Пусть, например, на
вход программе поданы следующие символы:
a1ab11ac1ad2ae4r4t3а1!
В данном случае программа должна вывести 24!/500.
